# 🪐 おえかきプラネット

紙に描いた絵をカメラでスキャンすると、海・陸・空のワールドで自分の絵が動きだすブラウザアプリ。
リトルプラネットの「描いた絵が動きだす」系アトラクションや teamLab「お絵かき水族館」と同じ仕組みのミニ版です。

**外部ライブラリなし** — マーカー検出・射影変換 (ホモグラフィ)・切り抜きもすべて素の JavaScript + Canvas で実装しています。

## 遊びかた

1. **🖨️ かみを いんさつ** — シートを A4 で印刷する。
   四隅に黒い正方形マーカーが印刷される (これが位置合わせの目印)。
   - ぬりえシート (さかな / とり / くるま): 輪郭に色を塗る
   - じゆうシート (✏️): 枠の中に好きなものを描く (輪郭は太いペンで閉じて描く)
2. 紙に自由に色を塗る。四隅の ■ マークは塗りつぶさないこと。
3. **📷 スキャン** — シート全体が写るように真上から写真を撮る (スマホならその場で撮影可)。
   - マーカーを自動検出して 4 点を提示。ずれていたら ● をドラッグして補正できる。
4. **✨ よみとる!** → プレビュー → **🌊 せかいへ はなつ!**
   (じゆうシートは放流先を うみ🌊 / そら☁️ / りく🛣️ から選ぶ)
5. ワールドで泳ぐ・飛ぶ・走る。タップすると喜ぶ。

プリンタがない場合は **🖍️ がめんで おえかき** モードで、画面上で直接塗って放流できます。

## 動かしかた

ビルド不要。ローカルファイルとして開くだけで動きます。

```sh
# そのまま開く
open little-planet/index.html

# またはローカルサーバで
cd little-planet && python3 -m http.server 8000
# → http://localhost:8000
```

スマホで使う場合は同一ネットワークの PC でサーバを立てるか、GitHub Pages などに置くと
`<input capture="environment">` でカメラ撮影がそのまま使えます。

## 仕組み

```
写真 ──▶ 二値化(大津) ──▶ 連結成分ラベリング ──▶ 四隅マーカー候補の選別
                                                       │
ぬりえシート座標系 ◀── 射影変換(DLT + バイリニア補間) ◀─┘
      │
      ├─▶ 紙の白からホワイトバランス推定・補正
      ├─▶ 切り抜き
      │     ├ ぬりえ: テンプレートのシルエットパスでマスク
      │     └ じゆう: インク検出 → 膨張処理 → 縁からフラッドフィルで
      │              「線に囲まれた内側」を判定 → 最大連結成分のみ残す
      └─▶ スプライト化 ──▶ ワールドへ投入
                              ├ さかな: 縦ストリップを位相差で揺らして泳ぎを表現
                              ├ とり  : 翼側の半分を伸縮させて羽ばたきを表現
                              └ くるま: 道路上をバウンドしながら走行
```

- マーカー検出に失敗しても、4 点を手動ドラッグで合わせるフォールバック UI がある
- スキャン結果は `localStorage` に保存され、次回起動時にワールドへ復元される
- じゆうモードは輪郭が閉じていなくても失敗にはならず、線の部分だけが切り抜かれて動く

## ファイル構成

```
little-planet/
├── index.html        画面
├── css/style.css
└── js/
    ├── templates.js  ぬりえテンプレート定義 + 印刷シート描画
    ├── scan.js       画像処理 (二値化 / ラベリング / ホモグラフィ / 切り抜き)
    ├── world.js      ワールド描画とアニメーション
    └── app.js        UI 制御
```
